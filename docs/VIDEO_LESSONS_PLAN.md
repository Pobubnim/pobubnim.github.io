# ПОТОК МИКРО-ОБУЧАЛОК ПОБУБНИМ (заведён 25.08.2026)

Зачем: отвечать роликами на реальные запросы людей (WordStat, docs/SEO_KEYWORDS.md),
собирать охват в соцсетях и уводить в обучение (education.html, от 3 000 ₽/занятие).

## Формат

- Вертикаль 9:16, 1080×1920, 30–45 секунд (канон соцсетей — вертикаль, альбомы).
- Структура: ХУК (вопрос запроса, ≤3 с) → ТЕЛО (3 конкретных совета/факта, без воды)
  → CTA («полный разбор и обучение — ПОБУБНИМ», адрес сайта).
- Голос: бренд-голос Fish Audio (монолитовский конфиг
  `monolith_assistant/scripts/fish_config.local.json`, голос 868377a7, s2.1-pro-free).
- Визуал: стиль сайта — чёрный фон #000, крем #f5efe2, Inter Tight + Playfair Display
  italic акценты, вспышки кадров из фонда СЕВЕРСВЕТ (hotlink-исходники локально:
  C:/src/seversvet/site/assets/film|work).
- Сборка: hyperframes (кадры ПОСЛЕДОВАТЕЛЬНО инлайн, коммит после каждого кадра —
  закон token economy). Титры-обложки — HTML.

## Конвейер одного ролика

1. Сценарий: hook/тело/CTA + партитура `videos/<slug>/voice.json`.
2. Озвучка: `python C:/src/monolith_assistant/scripts/tts_fish.py --script voice.json --outdir audio`.
3. Кадры: hyperframes-композиция по сценам, вставки работ из фонда СЕВЕРСВЕТ.
4. Рендер 9:16 → приёмка владельцем (стоп-кадры + прогон) → публикация.
5. Публикация: TG-канал «Побубним за видео» + VK + страница на сайте (раздел уроков).

Медиа (mp4/wav) в git НЕ кладём — только сценарии, партитуры и превью-кадры.

## ДИЗАЙН-КАНОН РОЛИКОВ (закон владельца, 25.08.2026, ролик №1)

1. **Кадры-фотографии НИКОГДА не на весь экран** — сжатые webp растянутые в 9:16
   это брак. Кадры живут только в окнах-мониторах 16:9 с рамкой, скруглением,
   тенью и плашкой метаданных (`.monitor` в log-i-grade/index.html).
2. **Плашки и свой UI вместо голых кадров**: карточка клипа (бейдж LOG, скоуп-
   гистограмма, строка BRAW·10bit·ISO), панель «как в DaVinci» (колёса
   LIFT/GAMMA/GAIN на conic-gradient, ползунки CONTRAST/SATURATION) — авторский
   почерк колориста, ни у кого такого нет.
3. **Титры объёмные**: Playfair italic 700 + многослойная letterpress-тень
   (`.deep`), появление с back.out и лёгким поворотом.
4. **Моушен всюду**: каскады строк, карточки въезжают с противоположных сторон,
   скоуп «дышит» (stagger scaleY), REC-точка мигает (конечный repeat), кен-бёрнс
   внутри окна, вайп лог→грейд с бегущей шторкой.
5. Библиотека приёмов переносится из ролика в ролик — копировать блоки
   `.monitor`, `.davinci`, `.scope` из log-i-grade/index.html.

## ГЕЙТ СБОРКИ РОЛИКА (закон владельца, 25.08.2026 — КАНОН, скилл ~/.claude/skills/video-gate)

Ролик не собирается и не сдаётся без письменных ответов в `videos/<slug>/gate.md`.

ГЕЙТ А — до сборки, вместе со сценарием:
1. **Аудитория и запрос** — на чей запрос отвечает (WordStat + частота, портрет зрителя).
2. **Сообщение и темы** — что несёт ролик, 3 тезиса без воды, каждый отвечает зрителю.
3. **Хук** — что держит первые 3 секунды, формулируется отдельной строкой.
4. **Опора** — разобранные успешные аналоги, какие материалы изучить, чего у нас не хватает.
5. **Факты** — всё проверено; осознанные упрощения помечены («упрощение: …, почему допустимо»).

ГЕЙТ Б — приёмка после рендера, до отправки владельцу:
6. **Динамика** — хронометраж сцен; сцена без движения дольше ~3 с = брак; смена
   композиции между соседними сценами.
7. **Фишки** — применённые приёмы + что нового ушло в библиотеку.
8. **Профессиональность** — планка «не отличить от студийной моушен-графики», дизайн-канон
   соблюдён, стоп-кадры каждой сцены смотреть глазами.
9. **Озвучка — не ИИшная** — ударения на рисковых словах акцентом («дорого́й», «кино́шности»),
   вопрос не одним словом, а с подводкой («Ну что — побубним?!»), нажим короткими
   предложениями («Серое. Плоское. Блёклое.»), паузы `(break)` при normalize=false,
   транскрипт-проверка Whisper после генерации. ⚠ Акцент «и́» у Fish мутирует гласную
   («Побубни́м» → «побубнем», А/Б-транскрипт 25.08) — слова с ударной «и» без метки.

## Инструменты: вердикт по аналогам (разведка 25.08.2026)

hyperframes (HTML+GSAP, локальный рендер, скиллы агента) — ОСТАЁМСЯ. Аналоги:
Remotion (React, ~60K скачиваний/нед) — мощнее экосистема, но тяжелее цикл и
чужой стек; Motion Canvas (~8K) — ручные генераторы, не для конвейера; Revideo
(~3K) — форк Motion Canvas для автоматических пайплайнов, следить. Рендер у всех
как у нас — браузерные скриншоты. Преимущество hyperframes для нас: агент сам
пишет HTML в стиле сайта, шрифты и токены ПОБУБНИМ переносятся 1:1.
Ассеты: `media-use` (каталог HeyGen: BGM 10k+ треков, SFX, иконки) — для
подложечной музыки следующих роликов; фонд кадров — СЕВЕРСВЕТ (105 видео).
Источники: [pkgpulse](https://www.pkgpulse.com/blog/remotion-vs-motion-canvas-vs-revideo-programmatic-video-2026), [rendercomp](https://rendercomp.com/blog/best-programmatic-video-tools-2026/), [autoae](https://autoae.online/blog/remotion-alternatives-compared-2026).
