## Разведка: что нужно сфере (мировые эталоны → пустые ниши рунета)

Эталоны: StudioBinder (shot list, call sheet, раскадровка — фримиум),
CineFlo (shot list + DoF-калькулятор + экспонометрия + lighting ratio),
shotlist.tools и toolsforfilm.com (бесплатные одностраничники без регистрации),
Boords/Studiovity (AI-раскадровки). В рунете живых бесплатных аналогов НЕТ
(выдача — курсы и CapCut), ниша пустая.

## Принципы каждого инструмента (не нарушать)

1. Бесплатно, без регистрации, всё в браузере — данные не уходят (это в hero).
2. «Вместо оплаты — спасибо в личку» + просьбы из лички = источник очереди.
3. Опции-карточки слева, живой лист справа (paper.css); марки «Б» по диагонали.
4. Выгрузка: копировать / настоящий .docx (docx.js) / печать-PDF.
5. Числа и юр-формулировки — только сверенные (ГК РФ, EDU_BASE, источники §8а);
   имитации подписываются.
6. SEO: title/H1 с запроса, schema WebApplication+FAQPage+Breadcrumb, FAQ на
   странице, перелинковка с релевантными статьями, sitemap, IndexNow.
7. Мобила: min-width:0 в гридах, проверка scrollWidth на 375px.
