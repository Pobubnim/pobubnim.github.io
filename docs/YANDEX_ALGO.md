# АЛГОРИТМЫ ВЫДАЧИ ЯНДЕКСА И ИИ-ОТВЕТЫ (разведка 25.08.2026)

Зачем: попадать в топ классической выдачи И в генеративные ответы (Нейро /
«Поиск с Алисой»), которые Яндекс подкладывает над результатами.

## Как Яндекс ранжирует (база)

1. Приоритет сигналов: **title + description → H1–H2 → текст** (закон Руслана,
   подтверждён практикой) + поведенческие факторы (CTR сниппета, возвраты в выдачу).
2. Гео-привязка обязательна для коммерческих запросов: город в мета/H1 +
   карточка Яндекс.Бизнес (в очереди!) + region в Вебмастере.
3. YATI (трансформер) оценивает СМЫСЛ текста, не плотность ключей: страница
   должна ОТВЕЧАТЬ на запрос, а не содержать его N раз.
4. Поведенческое: быстрая загрузка, мобильная вёрстка, отсутствие агрессивных
   попапов. Наш статик на Pages это закрывает по определению.

## Как попасть в ИИ-ответы (Нейро / Алиса) — 5 условий

Нейро собирает ответ из 3–5 источников (YandexGPT + BERT-оценка фрагментов).
Отбор источников:

1. **Топ-20 классической выдачи** — вне его страницы не рассматриваются
   (сначала обычное SEO, потом GEO).
2. **Чёткий ответ в первых двух предложениях** блока — без длинных подводок.
3. **Микроразметка FAQPage** — наши сервисные, гео-страницы и статьи уже с ней.
4. **Экспертность**: автор с регалиями (Person-schema с jobTitle есть),
   первоисточники, даты обновления.
5. **Упоминания бренда вне сайта**: СМИ, справочники, отзывы, соцсети
   (наши ВК/TG/Дзен работают на это).

Требования к тексту: абзацы самодостаточные (вырываются из контекста),
факты кратко и однозначно, ответ РЯДОМ с вопросом-заголовком.
CTR органики при ИИ-ответе падает ~34%, но ИИ-трафик конвертит в 2–3 раза лучше.

## Что уже сделано на pobubnim (25.08)

- FAQPage + Person + Service + BreadcrumbList schema на всех ключевых страницах
- Гео в title/description/H1 (Москва и МО + 3 города-лендинга)
- Статьи с прямым ответом в первом абзаце («Короткий ответ: …») — формат Нейро
- IndexNow-пинг после каждого деплоя

## Очередь (следующие сессии)

1. Яндекс.Бизнес карточка (сильнейший гео-сигнал) → Яндекс.Услуги анкета.
2. В Вебмастере: регион сайта, проверка «Качество» после переиндексации.
3. Даты обновления на статьях (уже есть <time>) — освежать раз в квартал.
4. Внешние упоминания: Дзен-канал (есть), справочники (2ГИС, Zoon — руками
   Савелия или с подтверждением), профильные каталоги видеографов.
5. ai-search.org (просьба владельца): из моего окружения сайт не открылся
   (error page). По скриншоту — нишевый ИИ-поисковик. Отдельного «попадания»
   не существует: такие движки едят тот же индекс и те же GEO-сигналы
   (FAQ, прямые ответы, упоминания бренда). Правила выше покрывают и его;
   вернуться, когда сайт будет доступен.
