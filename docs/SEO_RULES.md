## Как читает поисковик (порядок приоритета)

1. **`<title>` и `<meta description>`** — главные теги, поисковик смотрит на них прежде всего.
2. **H1, затем H2** — заголовки страницы.
3. **Текст на странице** — в последнюю очередь.

Вывод: запрос и город живут СНАЧАЛА в title/description/H1, и только потом в тексте.

## Геопривязка — обязательна

- Без города в мета и заголовках локальный поиск НЕ РАБОТАЕТ вовсе (урок 25.08:
  на всём сайте не было слова «Москва» — ноль шансов по «видеограф москва»).
- Город — в title, в description и хотя бы в H1 каждой ГЕОзависимой страницы
  (съёмка, свадьбы, мероприятия, клипы, портфолио).
- Дистанционные услуги (сайты, боты, удалённая цветокоррекция) — БЕЗ фейкового
  гео; там честное «удалённо / по всей России».
- Наши города: **Москва** (главный запрос), **Наро-Фоминск**, **Московская область**.

## Правила тегов

- **Title**: 50–65 символов, запрос в начале («Видеограф в Москве — …»),
  бренд `| ПОБУБНИМ` в конце (может обрезаться — не страшно). Уникален на каждой странице.
- **Description**: 150–190 символов, запрос + гео + конкретика (цены «от …») + CTA.
  Уникален, не дублировать между страницами.
- **H1**: ОДИН на страницу и он ОТВЕЧАЕТ НА ЗАПРОС. Арт-заголовок («Снимаю. Крашу…»)
  сохраняем приёмом: запросная строка-label с гео кладётся ВНУТРЬ `<h1>` первым
  `<span class="label">` (в CSS `h1 .label { display:block }`) — вид не меняется,
  семантика становится запросной. Скрытый текст (display:none) ЗАПРЕЩЁН — фильтр.
- **H2**: запросные там, где не ломают тон («Сколько стоит видеосъёмка», не «Сколько
  это стоит»). Арт-H2 допустимы, но не все подряд.
- **Schema.org**: ProfessionalService с `areaServed` списком городов (@type City),
  `address` (Наро-Фоминск, Московская область) и `telephone` +7 982 905-44-54.
  NAP (имя-адрес-телефон) ВЕЗДЕ одинаковый с карточкой Яндекс.Бизнеса (id 194158975904).
- `<meta name="author" content="Савелий Бубнов">` на каждой странице.

## Ритуал после правок

1. Проверить вид локально (file:// или превью) — label в hero не сломан.
2. Коммит + push (Pages деплоит сам).
3. Пинг IndexNow: ключ `192a35e5815990c4c58d2bff8e132937.txt` в корне,
   POST на api.indexnow.org со списком изменённых URL.
4. При структурных изменениях — переобход в Яндекс.Вебмастере и GSC.
