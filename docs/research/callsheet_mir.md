## 2. Функции конструктора
- Reorderable sections: показать/скрыть/переставить блоки, колонки, заголовки секций редактируются; сохранение как шаблон [прочитано] StudioBinder S2,S7; Yamdu «500+ customizable elements» S6; SetHero drag-and-drop S3.
- Автоподстановка из расписания/списка актёров/локаций [прочитано] StudioBinder S2, Celtx S9, Filmustage S10. Yamdu: «enter once, flows through every document» [выдача] S5.
- Cascading time changes: сдвиг одного времени автоматически двигает связанные [прочитано] SetHero S3. Yamdu: «push or pull call times» в один клик [прочитано] S6. Для нас: «сдвинуть всё на ±N минут» и «сдвинуть начиная с этого блока».
- Детекция опечаток во времени, расчёт переработки (overtime, через AI) [прочитано] SetHero S3. Серверной не надо: правила простые (обед позже 6 ч, wrap раньше начала, время приезда после call).
- Персональные call times на каждого (разные для актёров и цехов) [прочитано] SetHero, StudioBinder, Yamdu S2,S3.
- Упрощённая версия для актёров vs подробная для crew [прочитано] StudioBinder S2.
- Повторное использование: база контактов, mailing-list, «добавить всю группу одним кликом», внешние контакты [прочитано] Yamdu S5; contact database StudioBinder S2; SetHero «cast and crew contact management» S5.
- Шаблоны: сохранить как шаблон между проектами [прочитано] StudioBinder, Yamdu S6,S7. Образцы для feature films и photoshoots [прочитано] S7 — отдельный шаблон «фотосессия» это признанный сценарий.
- Печать: 2 варианта шаблонов Modern и Compact [прочитано] Dramatify S8. Excel-экспорт [прочитано] SetHero S3, Filmustage (скоро) S10. PDF у всех.
- AI-черновик из сценария PDF с «confidence levels» [прочитано] CallSheetX S11 (не для нас: нужен сервер).
- Правило «разослать за 10 часов до general call» [прочитано] StudioBinder S1 — основа для проверки готовности/напоминания.
- Day-out-of-Days отчёт [прочитано] SetHero S4 (редкое для 2-15 человек).
- Production report из дня съёмок [прочитано] SetHero, Yamdu, G-Casper S5,S12 — редкое.

## 3. Рассылка и подтверждения
- Каналы: email + SMS (StudioBinder, SetHero) [прочитано] S2,S3; в Yamdu SMS нет, но приложение/дашборд [выдача] S5,S12; в сравнении SMS только у SetHero и Simple Callsheet [прочитано] S12.
- Статусы доставки: sent / viewed / confirmed / undeliverable [прочитано] StudioBinder S7; SetHero «delivery failure notifications» S3; Yamdu «sending report» [выдача] S5.
- Подтверждение получения (confirm) в один тап со смартфона [прочитано] StudioBinder S13. Есть у SetHero, StudioBinder, Yamdu, Celtx, Koala, Assemble [прочитано] S12.
- Трекинг просмотров «87% Viewed, 52 Crew Confirmed» [прочитано] CallSheetX S11.
- Напоминания: reminder emails неподтвердившим [прочитано] StudioBinder S7; SetHero «one-click resend to unopened» и auto-followup (скоро) S3.
- Ревизии: «revision broadcasting в один клик», рассылка последней минуты отдельному получателю [прочитано] SetHero S3, StudioBinder S7; Celtx «track confirmations and revisions» [выдача] S9.
- Тестовое письмо себе перед рассылкой; добавление получателей после отправки; своё сообщение в письме [прочитано] Yamdu S6.
- Единая живая ссылка на актуальный лист + push + «ассистент» отвечающий на вопросы о времени [прочитано] CallSheetX S11.
- Рассылка по департаментам (адресные обновления) [прочитано] CallSheetX S11.
- Установка как мобильное веб-приложение [прочитано] CallSheetX S11.
Для «без сервера» применимо: персональные ссылки (wa.me, t.me/share), массовая отправка очередью «по одному», ручная отметка «подтвердил» в нашем листе, текст-напоминание для неподтвердивших, ревизия-«вышла версия 2: что изменилось» (дифф), вложение diff в сообщение. Серверный трекинг просмотров без сервера невозможен [знание].

## 4. Чего у нас нет (по ценности для группы 2-15 человек)
Исключены уже запланированные. Приоритет 1 = обязательно.
1. [1] Персональное время каждому (отдельное «вам к 08:30») — ядро SetHero/StudioBinder; у нас лишь время прибытия в строке. Уточнение: вывод в личное сообщение и в печать с подсветкой своей строки.
2. [1] Ручной статус подтверждения у каждого (отправлено / подтвердил / не ответил) + «текст-напоминание неподтвердившим одной кнопкой». Это бессерверный аналог delivery tracking.
3. [1] Номер ревизии + список «что изменилось» (дифф к предыдущей отправке) + водяной знак DRAFT/REVISED. Рассылка изменений; у SetHero «revision broadcasting».
4. [1] Каскадный сдвиг времён: «+15 мин всем начиная с…» (SetHero cascading, Yamdu push/pull).
5. [2] Проверки времени: обед позже 6 ч после call, конец раньше начала, приезд позже call, пересечения. Правила вместо AI-детекции опечаток.
6. [2] Advance schedule — уже запланирован «копия на следующую смену»; добавить именно блок «План завтра» на листе для цехов.
7. [2] Блок «Дата рассылки: за 10 ч до general call» — напоминание-срок и предупреждение, если лист не разослан.
8. [2] Упрощённый вид для актёров/клиента vs подробный для группы (скрыть телефоны, финансовые заметки). Приватность: делиться без телефонов.
9. [2] Перестановка/скрытие секций, свой логотип/цвет, водяной знак (всё в localStorage; логотип как dataURL).
10. [2] Cast-статусы SW/W/WF/SWF/H хотя бы как выпадающий список в строке актёра; остальные коды DOOD (I, R, T, WD...) не нужны.
11. [3] Walkie-каналы по цехам (редко даже у мировых: Yamdu, SetHero «скоро»).
12. [3] Background/extras со счётчиком голов, stand-ins, doubles; в клиповой/рекламной съёмке массовка есть.
13. [3] Quote of the day / «слово дня» — человеческая фишка SetHero, дешёвая.
14. [3] Режим «фотосессия» отдельным шаблоном (StudioBinder даёт образцы feature и photoshoot): без сцен, с моделью, визажистом, мудбордом, ссылкой на референсы.
15. [3] Вложения: ссылки на шот-лист/сториборды (файлов нет, только URL; у SetHero файлы, у нас — ссылки).
16. [3] Excel/CSV экспорт (SetHero) — наш .docx есть, CSV дёшево; полезно для групп, которые ведут таблицы.
17. [3] Два печатных макета Modern / Compact (Dramatify) — на 1 страницу A4 и подробный.
18. [3] 12/24 ч и °C/°F переключатели — для русской аудитории не нужны [знание].
Не делать (нужен сервер): трекинг просмотров, SMS-шлюз, push, AI из сценария, чат/«ассистент», дашборд с процентами.
