# Инструменты pobubnim: чего не хватает по лучшим бесплатным аналогам

Разведка по внешнему миру, наш код не читался. Пометки: [прочитано] страницу открыл; [выдача] только сниппет поиска; [знание] из памяти. Использовано ~20 вызовов.
Не найдено: toolsforfilm.com (поиск не дал страницы), CineFlo (не искал отдельно, мало вызовов), прямые русскоязычные аналоги шот-листа/ГРИП (в выдаче только калькуляторы стоимости видеопродакшна и блоги по свадебному таймингу).

## Шот-лист
Аналоги:
- StudioBinder Shot List Creator https://www.studiobinder.com/shot-list-creator/ [прочитано]: board-вид «как раскадровка», картинка к каждому кадру, группировка по сетапам/локациям/свету, перетаскивание сетапов, оценка времени на сетап, баннеры «переезд» и «обед», своя нумерация (цифры/буквы), цветовая маркировка, PDF с настройкой раскладки, ссылки только для просмотра, импорт сценария (fdx, fountain, PDF, doc) [выдача].
- shotlist.tools https://shotlist.tools/ [прочитано]: колонки setup/angle/lens/movement/subject/notes, сохранение в файл .lsl (XML) и открытие позже, без регистрации, навигация Tab по колонкам, печать в PDF. Диаграмм и шеринга нет.
- Shot Lister https://apps.apple.com/us/app/shot-lister/id529436218 [выдача]: Live Mode (график дня по минутам, видно отставание, пересборка за секунды), свои категории (реквизит, гардероб), раскадровка к каждому кадру, офлайн.
- Boords https://boords.com/shot-list-template [выдача]: раскадровка в шот-лист с настраиваемыми полями, animatic-превью, экспорт PDF/картинки/MP4.
Чего нет у нас (по описанию «уже умеет»): картинка-референс к кадру, группировка по сетапам (свет/позиция) и пересортировка под порядок съёмки, статус «снято/не снято» с живым режимом, свои колонки, файл-экспорт/импорт черновика.
ТОП-3 в браузере:
1. Группировка кадров по сетапу/локации + перетаскивание сетапов, сумма минут по сетапу, баннеры «переезд/обед» в расписании. [выдача, StudioBinder]
2. Режим «на площадке»: чекбокс «снято», прогресс «12/30», отставание от плана по минутам. [выдача, Shot Lister]
3. Референс-картинка к кадру: вставка из файла, уменьшение через canvas до ~320px и хранение dataUrl (внимание на лимит localStorage ~5 МБ; для больших лучше IndexedDB) [знание]; плюс экспорт/импорт .json-файла черновика (аналог .lsl).

## Чек-лист съёмочного дня
Аналоги:
- Milanote Film Equipment Checklist https://milanote.com/templates/filmmaking/film-equipment-checklist [выдача]: шаблон, настройка под многодневные съёмки, удобно с телефона.
- Movie Shorts Gear Checklist https://www.themovieshorts.com/gear-checklist [выдача]: колонка «relevant», своя копия, переиспользование на каждую съёмку.
- Fangs Film Gear: два готовых списка (1 камера со звуком, 2 камеры) [выдача].
- Cheqroom https://www.cheqroom.com/blog/equipment-packing-list/ [выдача]: сканирование, сверка по бронированию, что не вернулось.
- FilmDaft: чек-лист в Excel/ODF [выдача].
Чего нет у нас: профили под тип съёмки (одна камера/две, свадьба, интервью), «взять / не нужно» вместо только галочек, печать «пакинг-листа» по разделам, учёт возвращения техники после съёмки (две фазы: упаковал / вернул).
ТОП-3:
1. Пресеты набора по типу съёмки: отметка «не нужно сегодня» скрывает пункт. [выдача, Movie Shorts]
2. Две фазы: «упаковано» и «вернулось с площадки», отчёт «чего не хватает после съёмки». [выдача, Cheqroom, идея] 
3. Печать/копия текстом только невыполненного списка, группировка по разделам для кейса/рюкзака. [знание]

## Бриф на съёмку
Аналоги: русские калькуляторы-опросники videoglobal.ru/calculator.html, iq-cinema.ru/calc2/index.html, iconfilm.ru/calc [выдача] (тип, длительность, сроки, результат — смета «за 2 минуты»); HoneyBook templates с «smart fields» (подстановка имени клиента, проекта, даты) https://www.honeybook.com/templates/t/photography-agreement [выдача].
Чего нет у нас: бриф ведёт к смете (ответы автоматически становятся позициями сметы), ссылка-анкета для клиента (клиент заполняет у себя, ответ приходит в адресе обратно), подстановка полей между инструментами.
ТОП-3:
1. Ссылка-анкета: клиент открывает форму по ссылке с вопросами, заполняет, нажимает «Отправить фотографу» и получает ссылку/текст с ответами для мессенджера (без сервера, данные в hash). [знание]
2. «Из брифа в смету»: хронометраж, число локаций, срочность превращаются в позиции сметы. [выдача: русские калькуляторы так считают]
3. Общие поля (проект, клиент, дата) один раз на все инструменты: «Данные проекта». [выдача, HoneyBook smart fields]

## Смета и счёт
Аналоги: StudioBinder Film Budget Template https://www.studiobinder.com/blog/downloads/film-budget-template/ [выдача] (разделы ATL/BTL/Production/Post, Top Sheet, автосуммы, cashflow и PO-лог); HoneyBook / Bonsai [выдача] (шаблоны, смарт-поля, e-signature, подписание онлайн).
Чего нет у нас: Top Sheet по группам (съёмка/пост/техника), несколько вариантов («эконом/стандарт/премиум») рядом, количество×единица (смена, час, шт.), факт против плана, нумерация и дата счёта, НДС/УСН-режимы, платёжная часть (QR СБП/реквизиты) [знание].
ТОП-3:
1. Три пакета рядом (эконом/стандарт/премиум) с отметкой «рекомендуем» и один клик «сделать из выбранного счёт». [знание]
2. Разделы сметы с подитогами и Top Sheet; единицы «смена/час/шт.», доля пост-продакшна. [выдача, StudioBinder]
3. QR-код платежа по реквизитам (СБП/банковский QR) и срок оплаты с автонумерацией счёта. [знание, проверить формат]

## Ставка за смену
Аналоги: Harvest https://www.getharvest.com/calculators/hourly-rate-calculator-for-photographers, Imagen AI Photography Pricing Calculator https://imagen-ai.com/tools/photography-pricing-calculator/, solohourly, freelancecalc [выдача]. Отмечено: эффективная ставка после монтажа, дороги и правок на 25–40% ниже сессионной [выдача, freelancecalc]; «True Day Rate» от прибыли [выдача].
Чего нет у нас: учёт нефактурируемого времени (монтаж, переписка, дорога) и загрузки по неделям, сценарии «что если» (ползунки), оценка «сколько съёмок в месяц нужно».
ТОП-3:
1. Часы после съёмки (монтаж, дорога, правки) входят в расчёт, показать «эффективная ставка в час». [выдача]
2. Ползунки загруженности (смен в месяц), мгновенный пересчёт цены дня и дохода. [знание]
3. Мост «ставка → смета»: подставить ставку как позицию. [знание]

## Тайминг свадебного дня
Аналоги:
- Gather Shot Timeline Builder https://gathershot.com/tools/wedding-day-timeline-builder/ [прочитано]: закрепление (pin) события на фикс-время, остальное пересчитывается; drag-and-drop; подсказка буферов 10–15 мин; шаблон со средними длительностями (церемония 20–45 мин, коктейль 45–75); PDF; без регистрации.
- Custom Wedding Timeline https://customweddingtimeline.com/ [выдача]: закат/золотой час по дате и месту, советы из 500+ свадеб, списки семейных групп, письмо вендорам.
- Griffin Creative Co https://griffincreativeco.com/wedding-day-timeline-builder/ [выдача]: сколько часов съёмки нужно по описанному дню.
- Kings Films https://kings-films.com/wedding-timeline-generator/ [выдача]: золотой час автоматом под закат места.
- planning.wedding/timeline [прочитано]: пример с 8:00 до 22:30, перестановка, печать, без регистрации.
- Русские: wedwed.ru, onlywed.ru/timing, boyarovweddings.ru [выдача]: статьи и шаблоны, настоящего конструктора со сторонними функциями не видно.
Чего нет у нас: pin событий, подсказки буферов, закат из NOAA (у нас уже есть в вызывном листе, можно переиспользовать), расчёт «сколько часов съёмки нужно», список семейных групп для формальных кадров, версия для клиентов и подрядчиков.
ТОП-3:
1. Pin: закреплённое событие не двигается при пересчёте остальных, предупреждение о нехватке буфера <10 мин и пересечениях. [прочитано, Gather Shot]
2. Золотой час/закат по городу и дате прямо на шкале, предупреждение «портреты после заката». [выдача, Custom Wedding Timeline; формулы NOAA у нас уже есть]
3. «Сколько часов нужно фотографу/видеографу» по составу дня + список семейных групп для формальных кадров. [выдача, Griffin / Custom Wedding Timeline]

## Калькуляторы (ГРИП, ND, карта памяти)
ГРИП:
- PhotoPills DoF https://www.photopills.com/calculators/dof-advanced [выдача; прямое открытие 403]: CoC по размеру отпечатка, дистанции просмотра, остроте зрения; гиперфокальная, ближняя/дальняя границы, глубина впереди и позади.
- DOFSimulator https://dofsimulator.net/en/ [прочитано]: визуальная симуляция размытия и боке (5–9 лепестков), база камер и объективов, анаморфот/конвертеры, дифракция и оптимальная диафрагма, размытие фона в мм и % сенсора, ссылки с настройками.
ND:
- PhotoPills Exposure calculator, Long Exposure Calculator (app) [выдача]: выдержка с ND, таймер обратного отсчёта для >30 с, таблица значений экспозиции.
Карта памяти:
- Camera Data Calculator https://cameradatacalculator.com/ [прочитано]: 145 камер, ~6169 битрейтов по документации производителей, запас карты 0/5/10/20%, число карт, время записи на карту, «когда менять карту», «copy shoot summary», работает офлайн (PWA).
- Starlight Tools, data-calc.com [выдача]: ProRes/H.264/H.265/BRAW, время переноса, несколько камер.
Чего нет у нас: картинка-симулятор (предпросмотр размытия), коэффициент дифракции, ND с таймером, режимы мульти-камера, время копирования на диск (DIT), чек «хватит ли карт на день» с разбивкой по камерам.
ТОП-3:
1. Мини-симулятор ГРИП на canvas: силуэт на фоне с размытием по расчётному диаметру пятна размытия, плюс ссылка с настройками. [прочитано, DOFSimulator]
2. ND-таймер: выдержка с ND и обратный отсчёт для длинных, готовая таблица ступеней. [выдача]
3. Карты: запас 10–20%, число карт на день, несколько камер, время копирования на диск. [прочитано, Camera Data Calculator; время переноса: выдача]

## Конструкторы документов (договор, аренда, релиз, согласие на ребёнка)
Аналоги: Imagen AI Wedding Contract Generator https://imagen-ai.com/tools/photography-wedding-contract-generator/, Rocket Lawyer, PandaDoc, ShutterDeck, Iris Works [выдача]. Ключевые пункты, которые у них считаются обязательными: дата/время/место, сдаваемые материалы, оплата, отмена, авторские права и использование, ограничение ответственности [выдача]. Добавляют e-signature (ESIGN, eIDAS) [выдача]; смарт-поля, автозаполнение из данных клиента [выдача].
Чего нет у нас: переключатели необязательных пунктов с пояснением «зачем это», сроки сдачи/пересъёмки/форс-мажор/предоплата с возвратом, лист подписей с датами, версия «для клиента» (простым языком).
ТОП-3:
1. Каждая оговорка с переключателем и подсказкой «зачем и что будет, если убрать»; предпросмотр документа рядом. [знание, выдача по пунктам]
2. Данные сторон один раз на все документы (профиль исполнителя): договор, счёт, релиз подставляются сами. [выдача, HoneyBook smart fields]
3. Печать с местом подписи/даты и нумерацией страниц + оговорка «не заменяет юриста». [знание]

## Общие удобства
Что хорошие конструкторы делают для понятности и привлекательности:
- Пример одним кликом и «очистить»: у Gather Shot есть готовый шаблон со средними длительностями [прочитано]; у планировщиков всегда есть образец дня [прочитано, planning.wedding].
- Файл на диск и обратно: shotlist.tools сохраняет .lsl и открывает позже без облака [прочитано]. Нам: «Скачать файл .json / Открыть файл» в каждом инструменте.
- Несколько документов: StudioBinder держит архив [прочитано]. Нам: список «Мои черновики» (название, дата правки) по инструменту, дублировать/удалить с отменой, ключи localStorage с префиксом [знание].
- Прогресс заполнения: «обязательных полей заполнено 5/8», шкала над формой, отметка что мешает отправить [знание; аналогично Shot Lister «сколько снято»].
- Пустые состояния: вместо пустой таблицы кнопка «Добавить первый кадр / Вставить пример» и 1 строка «зачем это» [знание].
- Подсказки: подсказки буфера 10–15 минут у Gather Shot [прочитано], «relevant» и пояснение у чек-листов; знак «?» с коротким примером [знание].
- Общие данные проекта: проект/клиент/дата вводятся один раз, видны во всех инструментах [выдача, HoneyBook smart fields].
- Экспорт: PDF через печать (shotlist.tools), копия shoot summary (Camera Data Calculator) [прочитано]; ссылка с настройками (DOFSimulator) [прочитано]; PWA-офлайн «Works offline» [прочитано, Camera Data Calculator]. Нам: manifest + service worker, чтобы открывать на площадке без сети [знание].
- Шеринг: ссылки только для просмотра (StudioBinder) [прочитано]; у нас — ссылка с черновиком в адресе, ограничение длины URL ~2000 знаков, сжатие через CompressionStream [знание].
- Клавиатура: Tab между колонками (shotlist.tools) [прочитано]; Enter добавляет строку, Ctrl+Z [знание].

## Не проверено
toolsforfilm.com, CineFlo, Notion-шаблоны, Assemble, WeddingWire/Zola/The Knot конструкторы тайминга, русскоязычные аналоги шот-листа: прямых страниц не открывал (лимит вызовов). Страница PhotoPills DoF вернула 403, данные по ней только из выдачи.
