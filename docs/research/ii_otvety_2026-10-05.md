## ИТОГ (б) Правки по убыванию ожидаемой отдачи

Оговорка: «отдача» оценена по силе источника и по тому, что блокирует попадание сейчас; измеренного прироста нет и не будет (разд. 5: измерение ИИ-трафика почти невозможно).

1. [владелец в кабинете, 15 мин] Яндекс Вебмастер -> Эффективность -> «Видимость сайта в Алисе AI»: SoV, примеры запросов и страниц, конкуренты. Без этого неизвестно, цитируется ли сайт уже, и по каким запросам. Источник: https://yandex.ru/support/webmaster/ru/service/alice-answers [П].
2. [владелец на площадках] Упоминания на сторонних площадках, которые Алиса цитирует. Замер Habr 19.08.2026: 455 ответов Алисы AI, 2976 ссылок, 454 сайта; чаще всего vc.ru (202), Дзен (124), Sostav (101), Habr (66), DTF (50) — вместе ~22% ссылок [В] https://habr.com/ru/articles/1072206/ . ## ИТОГ (в) Что не работает или не доказано

- llms.txt / llms-full.txt как рычаг: не доказан. Ahrefs (по пересказу [В]): 97% файлов получили ноль запросов в мае 2026; GPTBot 4,51%, ClaudeBot 0,80% запросов к llms.txt, 21,7% — SEO-аудиторы. Google прямо: «не нужно создавать AI text files» [П]. Яндекс публикует llms.txt и llms-full.txt для документации API Вебмастера (https://yandex.ru/dev/webmaster/doc/ru/llms.txt, открылся) — это карта для агентов-разработчиков, а не сигнал ранжирования; заявлений Яндекса о чтении llms.txt поиском не нашёл.
- Явный Allow для YandexAdditional(Bot): токен отказа, не заявка [П]. Ничего не добавляет.
- Google-Extended: к AI Overviews отношения не имеет [П].
- Дополнительная schema ради цитируемости: Ahrefs (11.05.2026, по пересказу [В]): 1 885 страниц добавили JSON-LD, за 30 дней цитирования ChatGPT +2,2%, AI Mode +2,4% (не отличимо от нуля), AI Overviews -4,6%; корреляция «цитируемые страницы в ~3 раза чаще с JSON-LD» объяснена общим качеством сайтов https://wearemachina.com/insights/schema-markup-explained и https://fractionalseo.services/blog/schema-markup-ai-citations-data/ (оригинал Ahrefs не открылся, 404 на моём адресе). Существующую разметку оставить: вреда нет и она нужна Яндексу/Google для сниппетов (FAQPage-статус в Google из памяти: поверхность ограничена, в этой разведке не проверял).
- «Формат: списки 59,5% цитирований» (GenOptima, Sostav 08.09.2026 [В] https://www.sostav.ru/blogs/293567/107191): речь о ТИПЕ страницы (листинги/подборки), не о маркированных списках внутри текста; прикладного вывода для нас нет.
- «ChatGPT = Bing»: не подтверждено вендором. Не строить план только на Bing.
- Вмешательство в ответ GigaChat/DeepSeek: механизмов не найдено ни у вендоров, ни в исследованиях.
- Отдельный pricing.md для ИИ: отклонено ранее; ничего нового не нашёл в пользу.

## ИТОГ (г) Как мерить (бесплатно)

1. Яндекс Вебмастер -> Эффективность -> «Видимость сайта в Алисе AI»: SoV, диапазон топ-3/10/20, примеры запросов и страниц, конкуренты; окно 3 месяца, обновление раз в неделю; считает только запросы, где сайт уже высоко [П]. Раз в неделю фиксировать цифру в docs/ (окно скользит, история теряется). API нет.
2. Bing Webmaster Tools -> AI Performance: цитирования в Copilot и Bing AI, grounding queries, выборка, без кликов, без ChatGPT [В].
3. Яндекс Метрика: сегмент «внешний реферер» по доменам chatgpt.com, openai.com, perplexity.ai, claude.ai, gemini.google.com, copilot.microsoft.com, deepseek.com, giga.chat, alice.yandex.ru. Ожидание: почти пусто. На замере Habr (90 дней, 634 визита) из 13 доменов сработали только yandex.ru и ya.ru, 10 визитов (1,6%), direct 87,1% — ChatGPT и чат Алисы реферер не передают [В] https://habr.com/ru/articles/1058796/ . Яндекс: отследить трафик из Нейро в Метрике и Вебмастере нельзя (по пересказу [В] https://datahints.ru/web-analytics-tools/yandex-metrika/analyzing-ai-traffic/ ; тезис датирован до запуска отчёта Вебмастера от 07.04.2026, а тот даёт показатели видимости, не клики).
4. `utm_source=chatgpt.com`: ChatGPT сам дописывает в ссылки на источники [В: пересказ OpenAI Publishers FAQ, страница 403 для моего WebFetch]. Смотреть в Метрике отчёт по меткам UTM / URL входа. В robots.txt `Clean-param` содержит utm_source — на Метрику не влияет (из памяти, не проверял).
5. Google Search Console: AI Overviews и AI Mode входят в отчёт «Web», отдельно не выделяются [П].
6. Ручная выборка: 10-15 запросов (например: «что такое вызывной лист», «образец вызывного листа», «сколько стоит цветокоррекция видео», «калькулятор ГРИП онлайн») в Алисе (поиск Яндекса, режим Алиса AI), GigaChat, DeepSeek без VPN. Каждый запрос трижды: Алиса возвращает тот же список в 67% повторов, ChatGPT в 32% [В Habr 1072206]. В таблицу: запрос, дата, цитируется ли pobubnim.ru, какой URL, кто вместо нас.
7. Серверных логов у GitHub Pages нет (из памяти, не проверял): заходы ИИ-роботов посчитать нельзя; проверка доступа — только `curl -A "<UA>"` (сделано 05.10.2026 для OAI-SearchBot: 200).

## 2. Остальные системы

ChatGPT (поиск):
- OpenAI: для видимости в поиске ChatGPT не блокировать OAI-SearchBot и пускать с опубликованных IP; «it can take ~24 hours from a site's robots.txt update» [П] https://developers.openai.com/api/docs/bots (бывш. platform.openai.com/docs/bots)
- GPTBot — обучение; ChatGPT-User — действия пользователя, «robots.txt rules may not apply» [П там же].
- Опт-аут OAI-SearchBot = сайт не показывается в ответах, остаётся навигационной ссылкой; ChatGPT ставит `utm_source=chatgpt.com` [В, пересказ Publishers FAQ] https://help.openai.com/en/articles/12627856-publishers-and-developers-faq (403 для моего WebFetch; ПЕРЕПРОВЕРИТЬ в браузере).
- «Поиск идёт через Bing»: сторонние статьи 2026 [В]; первичного подтверждения не нашёл. OpenAI в «Offline web search» пишет про «OpenAI's indexed and cached web content» [П по пересказу] https://help.openai.com/en/articles/20001203-offline-web-search-in-chatgpt. Итог: источник смешанный, доля Bing не доказана. Bing Search API закрыт с 11.08.2025 (кроме отдельных договоров) [В] https://www.seroundtable.com/bing-search-apis-retiring-august-11-2025-39406.html
- Россия: ChatGPT официально недоступен с российских IP [В; список стран OpenAI не открывал].

Perplexity:
- PerplexityBot — «surface and link websites in search results on Perplexity», не обучение; Perplexity-User — запросы пользователя, «generally ignores robots.txt» [П] https://docs.perplexity.ai/guides/bots
- Россия: доступность не подтверждена.

Claude:
- ClaudeBot — обучение; Claude-User — запросы пользователя; Claude-SearchBot — поиск. «Only Claude-SearchBot's blocking affects search visibility» [П] https://support.claude.com/en/articles/8896518
- Источник веб-поиска: по сторонним замерам Brave Search (79,2–87% цитат совпадают с топом Brave); Anthropic провайдера официально не называет [В] https://ranki.io/learn/how-to-get-cited-by-claude
- НАШ robots.txt: ClaudeBot (обучающий) назван, Claude-SearchBot и Claude-User нет; работает по `*`, блокировки нет.
- Россия: Claude официально недоступен [В].

Google AI Overviews / AI Mode:
- «There are no additional requirements to appear in AI Overviews or AI Mode, nor other special optimizations necessary»; нужна индексация и показ со сниппетом; «You don't need to create new machine readable files, AI text files, or markup»; управление — nosnippet / data-nosnippet / max-snippet / noindex; трафик AI-функций идёт в «Web» в Search Console [П] https://developers.google.com/search/docs/appearance/ai-features
- Google-Extended — токен для обучения/grounding в других продуктах Google, не про AI Overviews [П там же].
- Россия: AI Overviews доступны с мая 2025, AI Mode на русском [В] https://www.seonews.ru/events/ii-rezhim-ai-mode-v-google-stal-dostupen-v-rossii/ . ## 3. llms.txt: кто читает

- Ahrefs (по пересказу [В]): в мае 2026 97% файлов llms.txt получили ноль запросов; из запросов к файлу GPTBot 4,51%, ClaudeBot 0,80%, SEO-аудиторы 21,7%. Первичную страницу Ahrefs не открывал.
- Обзоры 2026: «OpenAI, Google и Anthropic не читают llms.txt в документированном виде и отсылают к robots.txt»; на июль 2026 ни один крупный вендор не документировал чтение [В] https://codersera.com/blog/llms-txt-complete-guide-2026/ , https://nohacks.co/episode/229-does-llmstxt-work-what-137000-domains-server-logs-show (137 000 доменов, логи — по заголовку, содержимое не открывал).
- Google: не нужны «AI text files» [П] https://developers.google.com/search/docs/appearance/ai-features
- Яндекс публикует llms.txt/llms-full.txt для документации API Вебмастера (проверено, открылось) — для разработчиков-агентов; про чтение llms.txt поиском не заявлял.
- ВЫВОД: файл держать (вреда нет, стоит копейки), llms-full.txt не делать: нет данных, что хоть один ИИ-поиск его читает. Отдачи не ждать.
