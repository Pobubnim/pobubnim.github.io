## Юр-канон конструктора договоров (сверено 25.08, обратка Руслана)

- Каркас: гл. 39 ГК РФ. Ступенчатые проценты удержания предоплаты ЗАПРЕЩЕНЫ
  (ничтожны для потребителя: ст. 782 ГК + ст. 32 ЗоЗПП).
- Форма брони выбирается кликом: аванс (возврат минус документально
  подтверждённые фактические расходы) / задаток ст. 380–381 (в тексте прямая
  квалификация «именно задаток, а не аванс», последствия симметричны:
  отказ заказчика — остаётся, отказ исполнителя — двойной возврат) / без.
- С потребителем задаток суды иногда переквалифицируют — хинт в интерфейсе есть.
- Суммы дублируются прописью (rubWords в dogovor.js).
- Портфолио — ст. 152.1; права: личное / коммерческая лицензия / отчуждение.
- Дисклеймер «не юрконсультация» на листе и в файлах — не удалять.

## Грабли (свежие)

- **Шрифты теперь СВОИ** (27.08): страницы подключают assets/css/fonts.css,
  Google Fonts не запрашивается — из России он регулярно подтормаживал.
  Меняете набор весов — прогоняйте `python tools/fetch_fonts.py` и проверяйте
  вид: без файла шрифты молча уедут в системный fallback. Исключение —
  архивная videos/log-i-grade (там свой набор, оставлена как была).

- **Длинная многострочная конкатенация в .js может не разобраться браузером**
  (26.08, kalkulyator-grip): файл компилировался через Runtime.compileScript,
  но при загрузке как внешний скрипт V8 давал SyntaxError на строке, где
  синтаксис верен. Причина не установлена; лечение — разбить выражение на
  переменные (`var crit = …; var note = …;`). Ловится приёмочным тестом:
  страница просто не поднимается, поэтому у каждого инструмента должен быть
  свой tools/test_*.py.

## Ритуал после правок

`python tools/audit_site.py` (0 ошибок обязательны) → проверка живьём
(сервер: preview pobubnim, python -m http.server 8765) + `python
tools/check_live.py` — он сам открывает страницы на 375 и 1280 и ловит
оверфлоу, ошибки консоли и битые картинки. Дальше коммит + push,
IndexNow-пинг изменённых URL (ключ 192a35e5815990c4c58d2bff8e132937.txt
в корне), правка задетых доков.
