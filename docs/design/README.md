# Дизайн-система v2 «Режиссёрский сценарий» (черновик 24.09.2026)

Сайт — фильм из сцен: автор ведёт посетителя **репликами**, **таймлайн** в шапке
показывает «где я и что дальше», каждая сцена кончается **склейкой** к следующей,
на экране одна крем-кнопка, на телефоне заявка всегда в **доке** под пальцем.

- `index.html` — сама система: диагноз, правила, структура «было/стало», токены, компоненты, макеты, план внедрения
- `ds.css` — токены и компоненты (единственный источник значений)
- `maket.html` — живой макет главной на новой системе (адаптив ПК/телефон; `#demo-picked` — состояние с выбранной задачей)
- `shots/` — кадры макета: `d-0*.jpg` (1440), `m-0*.jpg` и `mobile-screens.jpg` (390@2x), `*-full.jpg` — вся страница

Папка лежит в `docs/` — Jekyll её не публикует (`_config.yml`), на прод и в индекс не попадает.
Смотреть локально: `python -m http.server 8766` → http://localhost:8766/docs/design/

## Внедрено (24.09.2026)

Главная `index.html` пересобрана по системе: компоненты — `assets/css/scenes.css`,
поведение — `assets/js/scenes.js`, новые токены добавлены в `:root` `assets/css/style.css`
рядом со старыми (старые имена не трогались). Журнал и SEO-решения — docs/SEO_RULES.md, 24.09.
## Внедрено на весь сайт (25.09.2026)

Шаги 3–4: шапка из 4 разделов и подвал-навигатор на всех страницах (tools/build_nav.py),
таймлайн сцен, меню телефона и док (assets/js/nav.js), общие компоненты и шаблоны услуг
и статей (блок «ДС v2 на всём сайте» в assets/css/style.css). Реплика автора — на первом
экране услуг и в финальной сцене «Ваш ход» каждой страницы (заметка .cta-note стала
репликой). Склейка «Дальше» — в конце статей и уроков (.art-svc). Номер сцены над h2
совпадает с таймлайном. Затемнение заставки главной вернулось к уровню до v2 по слову
владельца (детализация ролика не падает). Не сделано: реплики внутри сцен услуг и склейки
между ними — очередь в docs/HANDOFF.md.
