# ПОБУБНИМ — pobubnim.github.io

Личный продающий сайт Савелия Бубнова: видеопродакшн, колористика, сайты,
приложения, интеграции. Канон — docs/SPEC.md. Статика без сборщиков,
деплой пушем в main (GitHub Pages).

- index.html — продающая главная (диалог заявки пишет в базу, см. docs/LEADS_ADMIN.md)
- admin.html — панель заявок владельца (вход по ключу; noindex, в навигации не светится)
- articles/ — статьи-разборы цен и гайды для новичков (SEO, docs/SEO_KEYWORDS.md)
- services/ — лендинги услуг; cases/ — страницы-кейсы (по файлу на кейс)
- assets/ — css/js/img/video (тяжёлые медиа в git не класть)
